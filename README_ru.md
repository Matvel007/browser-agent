## Обзор

**Browser Agent** — ассистент в боковой панели для Chromium-браузеров, включая Chrome и Яндекс.Браузер. Он читает страницы, кликает, вводит текст, переключает вкладки, смотрит консоль и сеть через DevTools Protocol и ищет в интернете. Вывод инструментов ограничен, большие данные сохраняются как артефакты, а сжатие контекста не удаляет переписку.

---

## Возможности

- **Любой провайдер** — RouterAI, AItunnel, OpenAI, DeepSeek, Google Gemini, Anthropic или любой OpenAI-совместимый сервер (OpenRouter, Groq, Ollama).
- **29 инструментов для браузера** — чтение страницы, действия с элементами, вкладки, JavaScript, консоль, сеть, DOM/CSS, скриншоты, производительность, отладчик, CDP-команды. Каждый инструмент можно отключить.
- **Веб-поиск** — DuckDuckGo по умолчанию, Tavily по желанию. Публичные ссылки читаются без открытия вкладки.
- **Ограниченный вывод** — каждый результат укладывается в профиль lean / balanced / full. Большие данные уходят в артефакты IndexedDB и передаются по ID.
- **Контролируемый контекст** — полная переписка хранится отдельно от того, что видит модель. `/compact` добавляет карточку сводки, сообщения остаются видимыми.
- **Свод действий** — все шаги одной задачи сворачиваются в один раскрываемый блок внутри ответа.
- **Плавающая кнопка** — круглая кнопка чата на странице. Перетащите её в зону «Закрыть», чтобы скрыть на этой вкладке.
- **Адаптивный интерфейс** — от панели шириной 320 px до десктопа, светлая и тёмная темы, звук завершения.
- **Два языка** — English и Русский, по умолчанию определяются из браузера.

## Стек

- **Платформа:** Chromium Manifest V3 (боковая панель, `chrome.debugger`, service worker)
- **Интерфейс:** [React](https://react.dev/) + [Tailwind CSS](https://tailwindcss.com/)
- **Сборка:** [Vite](https://vitejs.dev/), TypeScript
- **Тесты:** [Vitest](https://vitest.dev/) для модулей, [Playwright](https://playwright.dev/) для браузерных сценариев

## Установка

### Быстрая установка (без сборки)

1. Скачайте `browser-agent-1.0.0.zip` из [последнего релиза](https://github.com/Matvel007/browser-agent/releases/latest).
2. Распакуйте архив в папку, которую не будете удалять: расширение работает из этой папки.
3. Откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите эту папку.

### Из исходников

```bash
git clone https://github.com/Matvel007/browser-agent.git
cd browser-agent
npm ci
npm run build
```

Откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите папку `dist`. В других Chromium-браузерах процедура та же на странице расширений.

> Нужен Node.js 22.12+, 24 или 26+.

### Открытие панели

- Кнопка на панели инструментов
- `Alt+C` (меняется в настройках горячих клавиш браузера)
- Контекстное меню страницы
- Плавающая кнопка на странице

## Настройка

Откройте **Настройки** в панели:

- **Модели** — выберите провайдера, вставьте API-ключ, укажите модель. *Проверить подключение* отправляет один короткий запрос.
- **Инструменты** — включайте и отключайте каждый инструмент, настраивайте поиск.
- **Контекст** — реальное окно контекста модели, резерв ответа и порог сжатия.
- **Поведение** — дополнительные инструкции, лимит шагов, автоподключение CDP.
- **Интерфейс** — тема, язык, плавающая кнопка, звук.
- **Диагностика** — проверка возможностей браузера, хранилище артефактов, экспорт конфигурации без ключей.

API-ключи хранятся локально в расширении и не попадают в историю чата или экспорт.

## Ограничения

- `chrome.debugger` открывает только те домены CDP, которые Chromium разрешает расширениям.
- Консоль и сеть начинают записываться при подключении отладчика.
- Открытие встроенного DevTools может отключить отладчик расширения.
- DuckDuckGo может блокировать программные запросы; CAPTCHA показывается как ошибка.
- Некоторые сборки Chromium могут блокировать автозагрузку распакованного расширения — загрузите `dist` вручную со страницы расширений.

## Разработка

```bash
npm run typecheck    # проверка типов TypeScript
npm test             # модульные тесты
npm run icons        # пересоздать PNG-иконки из logo.svg
npx playwright install chromium
npm run test:e2e     # браузерные тесты по dist
```

Браузерные тесты используют временный профиль и подменённые ответы модели. Реальные ключи не нужны.
