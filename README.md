# 🤖 Chromium Agent

> Автономный ИИ-ассистент для Chromium-браузеров (Яндекс.Браузер, Chrome, Edge, Brave) с нативной боковой панелью, поддержкой российских провайдеров (RouterAI, AItunnel), глубоким управлением через **Chrome DevTools Protocol (CDP)** и интерфейсом в стиле современных сред разработки (OpenCode).

---

## 🌟 Возможности

### 1. 🪟 Интерфейс и темы оформления
* **Нейтральный браузерный дизайн**: сдержанные тона, чистая типографика, отсутствие навязчивых неоновых акцентов.
* **Светлая / Тёмная / Системная тема**: полноценная адаптация под оформление браузера и системы.
* **Строка ввода в 1 строку**: аккуратный фиксированный плейсхолдер *«Введите сообщение...»* без схлопываний и скачков высоты.
* **Селектор модели под строкой ввода (OpenCode-стиль)**: быстрый выбор *«Провайдер / Модель»* прямо под полем ввода.
* **Круговой индикатор контекста**: отображает загруженность контекстного окна в токенах, статус сжатия и статистику сообщений при наведении.

### 2. ⚡ Российские и мировые провайдеры (API)
* **RouterAI (Россия)**: официальный шлюз `https://routerai.ru/api/v1` с доступом к GPT-4o, Claude 3.5, DeepSeek и др.
* **AItunnel (Россия)**: официальный шлюз `https://api.aitunnel.ru/v1`.
* **DeepSeek**: официальный эндпоинт `https://api.deepseek.com`.
* **OpenAI**, **Google Gemini**, **Anthropic Claude**.
* **Пользовательский (Custom)**: OpenRouter, Groq, Ollama или локальный vLLM.
* **Динамическая подгрузка моделей**: кнопка в настройках загружает список доступных моделей из API с **автоматической фильтрацией** (исключаются фото-, аудио-модели и эмбеддинги, остаются только текстовые LLM).

### 3. 🎯 Сдержанный и профессиональный характер агента
* Агент не проявляет самодеятельности: при обычном приветствии («Привет») он просто вежливо здоровается и не сканирует страницу без просьбы.
* Браузерные инструменты (CDP) вызываются **только тогда**, когда пользователь прямо просит выполнить действие на странице (кликнуть, заполнить форму, проверить ошибки в консоли, исследовать сетевые запросы).
* Защита приватности: конфиденциальные данные (email, баланс, токены) не разглашаются без явного указания.

### 4. 🖱️ Плавающий виджет со свободным перетаскиванием (Drop-to-Close)
* Значок в виде **облачка чата** на каждой веб-странице.
* **Свободное перемещение по всему экрану**: перетаскивание мышью или тачем в любую точку экрана (X и Y) с запоминанием позиции.
* **Зона «Drop-to-Close»**: при перетаскивании внизу экрана появляется круглая зона *«ЗАКРЫТЬ»*. При сбросе в неё происходит эффектный разлёт частиц, и значок скрывается на время сессии вкладки.

### 5. 💬 Управление сообщениями и сессиями
* **Копирование**: кнопка копирования доступна как для ответов ассистента, так и для сообщений пользователя.
* **Откат сообщения (Rollback)**: стрелочка отката на сообщении пользователя возвращает его текст в строку ввода для редактирования и откатывает диалог до этого шага.
* **Менеджер сессий**: каждый запуск открывает чистый новый чат; история предыдущих сессий доступна в боковом меню с возможностью переключения и удаления.

### 6. 🌐 Локализация через XML
* Тексты интерфейса вынесены в `public/locales/ru.xml` и `public/locales/eng.xml`.
* Выбор языка: Авто / Русский / English.

## 🚀 Установка в браузер (Яндекс.Браузер / Chrome / Edge / Brave)

1. Откройте страницу расширений:
   ```text
   browser://extensions/  (или chrome://extensions/)
   ```
2. Включите **«Режим разработчика»** (*Developer mode*).
3. Нажмите **«Загрузить распакованное расширение»** (*Load unpacked*).
4. Выберите папку:
   ```text
   /run/media/anonim/Ventoy/Browser/dist
   ```
5. Плагин **Chromium Agent** установлен! Для вызова панели используйте:
   * Плавающий значок чата на любой веб-странице.
   * Горячую клавишу **`Alt + C`**.
   * Меню правой кнопки мыши: *«🤖 Открыть Chromium Agent»*.
