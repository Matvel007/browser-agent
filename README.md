# 🤖 DevTools AI Copilot for Chromium

> Нативное расширение для Chromium-браузеров (Chrome, Edge, Brave, Yandex) с окном в стиле **ChatGPT** в нативной боковой панели (**Side Panel**) и прямым доступом к **Chrome DevTools Protocol (CDP)** для автономного управления браузером.

---

## 🌟 Возможности

### 1. 🪟 Нативный интерфейс в стиле ChatGPT
* **Chrome Side Panel API**: не ломает верстку открытого сайта, плавно сосуществует с вкладками, сохраняет контекст.
* Минималистичная темная тема ChatGPT (`#212121`, `#171717`, `#2f2f2f`).
* Потоковый вывод сообщений (Streaming text chunk-by-chunk с мигающим курсором).
* Полный рендеринг **Markdown** (код с блоками подсветки, списки, таблицы).
* Быстрое копирование ответов и кнопка остановки генерации (Stop).

### 2. 🛠️ Управление браузером через Chrome DevTools (CDP)
В отличие от обычных расширений, этот агент подключается напрямую к протоколу отладчика Chrome (`chrome.debugger`):
* **Анализ Console & Ошибок**: видит ошибки JavaScript, предупреждения и логи консоли в реальном времени (`Console.enable`, `Runtime.exceptionThrown`).
* **Инспекция Network (Сеть & API)**: отслеживает запросы fetch/XHR, статус-коды (200, 404, 500), заголовки и ответы API (`Network.enable`).
* **Настоящие аппаратные клики (`Input.dispatchMouseEvent`)**: нажимает кнопки на уровне мыши (не синтетические события, обходит защиту, работает с React/Vue/Canvas).
* **Аппаратный ввод текста (`Input.dispatchKeyEvent`)**: печатает символы на уровне клавиатуры в любые инпуты и формы.
* **Скриншоты Viewport (`Page.captureScreenshot`)**: делает визуальные снимки прямо через CDP и показывает их в карточке шагов.
* **Выполнение JS (`Runtime.evaluate`)**: исполняет произвольные выражения в контексте страницы.
* **Инспекция структуры DOM**: глубокий анализ дерева элементов и accessibility.
* **Навигация и скроллинг**: управление переходами по URL и прокруткой.
* **Интерактивная подсветка**: при клике или вводе агент подсвечивает элемент зеленой рамкой на реальной веб-странице.

### 3. 🧠 Поддержка облачных моделей (Cloud APIs)
Универсальный селектор провайдеров в настройках:
* **OpenAI**: `gpt-4o`, `gpt-4o-mini`, `o3-mini`, `gpt-4-turbo`.
* **DeepSeek**: `deepseek-chat` (V3), `deepseek-reasoner` (R1) через официальный эндпоинт `https://api.deepseek.com`.
* **Google Gemini**: `gemini-2.0-flash`, `gemini-1.5-pro`.
* **Anthropic Claude**: `claude-3-5-sonnet-20241022`, `claude-3-5-haiku-20241022`.
* **Custom (OpenRouter / Groq / Ollama)**: настраиваемый Base URL и произвольное название модели.

## 🚀 Установка в браузер (Chrome / Brave / Edge / Yandex)

1. Откройте браузер и перейдите по адресу:
   ```text
   chrome://extensions/
   ```
   *(для Brave: `brave://extensions/`, для Edge: `edge://extensions/`)*
2. В правом верхнем углу включите переключатель **«Режим разработчика»** (*Developer mode*).
3. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
4. Выберите папку:
   ```text
   /run/media/anonim/Ventoy/Browser/dist
   ```
5. Расширение **«DevTools AI Copilot»** появится в списке и на панели инструментов браузера!
6. Закрепите иконку расширения (кнопка булавки) и нажмите на неё — справа откроется нативная боковая панель Chrome.

---

## ⚙️ Настройка

1. При первом открытии расширения откроется окно настроек (или нажмите на иконку шестерёнки ⚙️ в правом верхнем углу панели).
2. Выберите вашего провайдера (например, **OpenAI** или **DeepSeek**).
3. Вставьте ваш **API-ключ**.
4. Нажмите **«Сохранить»**. Ключ надёжно сохраняется в локальном хранилище расширения `chrome.storage.local`.

## 💡 Примеры команд агенту

* **Отладка веб-приложения:**
  > *«Проверь консоль этой страницы на ошибки JS и покажи, какие сетевые запросы API упали.»*
* **Исследование страницы:**
  > *«Сделай краткое саммари этой статьи и сделай скриншот первого экрана.»*
* **Автоматизация действий:**
  > *«Найди поле поиска на странице, введи туда "новости" и нажми кнопку поиска.»*
* **Анализ DOM:**
  > *«Покажи структуру блока с классом header и какие там ссылки.»*
